# ADAS Engineering Playground

A structured learning repository for Advanced Driver Assistance Systems (ADAS), organised as an engineering handbook.

## Current Study

The completed architecture study is documented in:

- [Highway Lane Following Test Bench Architecture](docs/02_architecture/Highway_Lane_Following_Test_Bench_Architecture.md)

## Repository Layout

- `docs/` — engineering notes and references
- `matlab/` — MATLAB exercises and scripts
- `simulink/` — Simulink models and subsystems
- `experiments/` — reproducible end-to-end projects
- `assets/` — diagrams and media

## Learning Path

1. ADAS fundamentals
2. Highway Lane Following architecture
3. Detailed perception, fusion, planning, control, and vehicle-dynamics studies
4. End-to-end ADAS experiments and research work
